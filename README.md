# Orçamento Fácil (Android)

App Android que abre a ferramenta de orçamentos da Metalúrgica Demak (PDF + Excel) dentro de um WebView.
O APK é compilado automaticamente pelo GitHub Actions a cada envio para a branch `main`.

Baixar: aba **Releases** > `apk-atual` > `Orcamento-Facil.apk`.

A ferramenta fica em `app/src/main/assets/index.html`.
